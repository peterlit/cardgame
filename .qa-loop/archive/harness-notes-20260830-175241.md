- Cheap cropping without building a tool: `sips -c <h> <w> --cropOffset <top> <left> in.png --out out.png`

  Cropping the header strip (offset 180, height 220) reads Moves/Time for a fraction of a full frame's tokens.
- Demo bar: while `demoing` or the completion banner is up, the header Moves/Time render as em-dashes
  (not 0/0:00) - use the presence of "-" as the demo-state assertion.
- The daily/casual distinction on the board is ONLY the 3-line objectives HUD strip under the pills.
  With the HUD up, tableau card i top y = 501 + 30*i (vs 425 + 30*i without it) - re-derive after any

- Running a whole demo line to completion is ~0.25 s/move (84 moves ~ 21 s). A plain `sleep 30` is
  blocked by the harness; use `until [ -f <flag> ]; do sleep 2; if [ $SECONDS -gt 34 ]; then touch <flag>; fi; done`.

## Chunk wf-6 (round 1)

- **Reset app state without a reinstall (3 s):** `xcrun simctl terminate`, then
  `plutil -remove 'causeway\.daily' <plist>` (and `causeway\.game`, `causeway\.wins`) on
  `$(xcrun simctl get_app_container <udid> <bundle> data)/Library/Preferences/<bundle>.plist`,
  then `xcrun simctl spawn <udid> launchctl stop com.apple.cfprefsd.xpc.daemon` and launch.
  **The dots MUST be backslash-escaped** — plutil reads `causeway.daily` as a key path and
  silently no-ops. A worker handed a "state-reset" device may still be dirty: check the Today
  card's tier circles before trusting it.
- zsh `rm -f *.png` in an EMPTY dir aborts the whole `&&`/`;` command list (nomatch) — a
  filmstrip loop chained after it never runs and you get a silent 0-frame film.
- MCP `tap`/`touch_path` land ~4-5 s after the call returns. A 30-frame host filmstrip
  (~9 s) started immediately before the call reliably brackets the gesture; always shoot a
  positive control (film + a `Next` tap → MAD ≈ 2.0) before believing a MAD 0.000 "no-op".
- Demo-bar geometry, seed 551879 (bronze line = 91 moves): ready/paused-1-line Next 236 /
  Start 297 / Stop 357 at y=263; running Pause 294 / Stop 357 at y=264; paused (2-line
  headline) Next 219 / Resume 289 / Stop 357 at y=266; completion banner single `Done`
  (356,266). Separator is `·` not `—`: "Winning line · 0 / 91".
- Daily sheet with the ⏰ line present: `Play` (200,672), how-to-win grid `🥉 Clear` (115,747),
  `🥈 Silver` (287,747), Gold/Flawless one row lower — no scrolling needed on 402x874.
- `sips -Z 500` on a crop that is 1206 px wide and 1500 tall yields a 402-pt-wide image, so

## Chunk wf-8 (round 1)

- **A whole WF-8 pass needs no card drags.** Toggle checkpoints are cheapest read from the
  prefs plist (`plutil -p <plist> | grep -i "autoplay\|autofinish"` → `causeway.autoplay` bool,
  `causeway.autofinishmode` ask|off|on) plus a ~5 KB pill crop:
  `sips -c 70 450 --cropOffset 495 10 full.png` = the Auto-finish pill alone.

  value and look like a dropped tap — re-read once before believing it.

  (`make_save.mjs --day 29 --tier flawless`): park with Auto-play **Off** + Auto-finish **Ask**
  so the restore is quiescent at Moves 92, then Not yet → toggle Auto-play (autoplay fires) →
  Auto-finish Ask→Off (no-op) →On (cascade to the overlay). ~12 turns total, vs ~30 for
  TC-8.4's 28-drag fixture.
- Pill x/y with a daily HUD + Finish pill present: Auto-play (337,135), Auto-finish (73,175),
  `Ready to finish` Not yet (127,497) / Finish (275,497). HUD objective chips crop:
  `sips -c 210 1206 --cropOffset 755 0` — the ✅/✗/· state of all three tiers in one tiny image.

## Chunk wf-7 (round 1)

- Deal alert on b2ce1a4, portrait 402x874, keypad NOT raised: field (200,461), Cancel (126,528),
  Play (274,528). **Clearing the pre-filled seed without the keypad:** long-press the field
  (touch_path dwell 900ms) -> `Select All` (142,413) -> MCP `text` replaces it in one turn. For a
  truly EMPTY field: dwell -> `Select All` (192,413) -> dwell again -> `Cut` (50,413).
- MCP `text` has **no backspace**: `"\b"` types two literal chars and `&#8;` types four. It also

  a user-reachable input, so don't file it.
- `Game.maxSeed` = 1,000,000 and the alert's hint/message/`enteredSeed` gate all agree; Play greys
  out for 0, blank, 9999999, 20 digits and junk. There is no `maxValidSeed` on this build.
- Pill x drifts with the deal's digit count: `Deal #10003` centre x=188, `Deal #551879` x=194,
  `Deal #1000000` -> Daily moves to x=297 (was 261). Re-read the row before tapping Daily/Wins.
