## Environment (verified 2026-09-09, loop 5)

- App: `com.whimsicaldistractions.Causeway`, Debug for the iOS Simulator. Workers this loop are
  `causeway-qa-1..3` (iPhone 17 Pro, iOS 26.5, 402 x 874 pt portrait) — pass YOUR udid everywhere.
- **Drive the app with the QADriver, not the MCP control tool** (the MCP tool needs a per-device
  human grant that is not available; the driver is a superset anyway). Read
  `.qa-loop/driver/README.md` once. Essentials, with `Q="python3 .qa-loop/driver/qa.py <udid>"`:
  `$Q launch CAUSEWAY_TODAY_OVERRIDE=2026-08-15` (the date pin — WORKFLOWS Fixture policy),
  `$Q tap X Y`, `$Q tapid <identifier>`, `$Q tapbtn <label>`, `$Q drag X1 Y1 X2 Y2`,
  `$Q type <text>`, `$Q alert`, `$Q labels texts|buttons|textfields|any [substring]` (ALL visible
  labels + frames + values in one 0.3 s call — use it instead of a screenshot whenever the question
  is "what does the screen say"), `$Q find <identifier>` (exists/hittable/frame/label),
  `$Q rotate landscapeLeft|portrait`, `$Q shot /abs/path.png` (1206x2622 px; ÷3 for points).
  Chain commands with `$Q --batch -` (one per stdin line). "driver not serving" → run
  `bash .qa-loop/driver/start.sh <udid>` (idempotent, ~10 s).
- Identifiers: cards `card.<S><rank>` (`card.D1` = A♦, `card.S13` = K♠; S = C/D/H/S; the label is
  "ace of diamonds"), toolbar `toolbar.newgame/undo/replay/autoplay/autofinish/deal/daily/wins/
  howtoplay/finish`, header `stat.moves` / `stat.time` / `stat.won`, daily sheet `daily.play` /
  `daily.cal.<idx>` / `daily.cal.prev` / `daily.cal.next` / `daily.cal.month` / `daily.clears` /
  `daily.lockednote` / `daily.demo.<tier>` / `daily.export` / `daily.import`, demo bar
  `demo.headline` / `demo.next` / `demo.start`, HUD `hud.day`, Wins `wins.dealentry.problem`.
- **Deal-# entry (2 taps):** `tapid toolbar.deal` (field is PRE-FILLED **and already focused** — no
  tap on it needed) → `selectall` → `type 500001` → `tapbtn Play`. Alert buttons sit at
  Cancel(57,368)/Play(205,368) with the pad up, but Play jumps to y=505 on an EMPTY field — always
  use `btn`/`tapbtn`. On a live game a second alert follows: `tapbtn "Play that deal"` /
  `Keep playing`. The **Wins** sheet's "Play a deal" field is NOT auto-focused: `tap 180 191` first.
- A `drag` with the default 0.15 s hold drives the app's manual card DragGesture (pickup + drop);
  `tapid card.H13` on a movable card = smart-move. Covered cards are not movable — check the column.
- Reset state: `xcrun simctl uninstall <udid> com.whimsicaldistractions.Causeway` then `install`
  from the .app path in your dispatch, then `$Q launch …`. There is no in-app reset.
- **Rotation WORKS through the driver** (`rotate`); loop 4's "impossible" notes were about the MCP
  toolset. `xcrun simctl ui <udid> content_size <category>` still works for Dynamic Type (sheets
  honour it live; the board's card/toolbar text is fixed-size). Reset to `large` when done.
